# gqodb-blocks

> **0.1.0 preview.** Experimental lossless block codecs for market data with Parquet counter-tests and benchmark tooling. Not a database. No stability promise: APIs, command-line tools and file
> formats may change in any 0.x release (see [API stability](https://github.com/GerritsenQuantOffices/GQODB/blob/main/docs/API_STABILITY.md)).
> Part of the [GQODB open layer](https://github.com/GerritsenQuantOffices/GQODB/blob/main/README.md); evidence and benchmark bounds are in
> the repository README.
> Parts of this README are in Dutch.

De werkende broncode en tests staan onder [`prototype/`](prototype/README.md).
Daar staan bouwcommando's, invoer/uitvoer, beperkingen en vervolgstappen.
